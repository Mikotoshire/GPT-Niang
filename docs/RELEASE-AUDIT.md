# 1.4.0 Windows 维护版发布审查

结论：80/100，可供小范围非商业测试发布，保留新设备验收限制。本记录是工程审查，不是法律认证或不存在未知漏洞的保证。

## 已修复的发布阻断项

- 旧打包器读取工作区文件，可能打包安装器生成的绝对路径 MCP 配置。现在只从指定 Git 提交读取 blob，按必需文件及附加许可清单构建，并强制验证便携 MCP 模板。
- 原主页下载链接和发布身份指向上游；现在主页、插件界面和发布说明标明 Mikotoshire 维护版、原作者出处及本仓库下载地址。
- 原发布流水线会联动未验证的 Mac 包，可能覆盖既有标签或文件。此分支改为显式 Windows 验证流程，关闭自动发布；发布不覆盖上游或已有 Release。

## 已检查的边界

- 额度读取仅使用 Codex app-server 的只读账户/额度协议；不为查询创建聊天或调用模型。MCP 只暴露额度查询工具，校验请求和消息大小。
- 账号匹配、单 worker 写入、失败缓存隔离、刷新超时、管道与文件队列恢复已有回归测试。
- 本地额度诊断使用严格字段白名单，轮转限制大小；真实运行状态和其他诊断不进入发行包。
- 上游 Release 更新由 fork-policy 禁止；没有新增遥测、维护者服务器或远程脚本执行入口。
- 启动/卸载的当前用户身份、任务动作、安装绑定、恢复路径检查保留；MSIX 实际路径启动已在本机验证。关闭自动更新不等于删除原恢复源码。
- Aether DLL 必须匹配固定公开哈希，MS-PL、代码 MIT、图片来源/非商业项目副本声明、语录许可全部随包分发。PNG 的文本与 EXIF 元数据列为扫描阻断项。

## 验证证据

- Node：87 项通过，1 项平台跳过。
- 物理模型：552 项断言通过；近地真实接触、横向碰撞/滑行测试通过；启动路径迁移 10 项断言通过。
- Python 发布测试：3 项通过，包括受污染工作区排除、便携模板强制检查、未知二进制/图片元数据拒绝、重复构建一致性。
- 安装器 22 项、更新/回滚 48 项隔离断言在此前启动修复验证中通过。本版发布时另外核验解压包的运行依赖与脚本；不将这些测试称作新设备真实账号安装。
- 构建器逐一扫描所有已提交文件，并逐字节核对 ZIP 内容。最终提交、文件数与结果以随 Release 提供的 RELEASE-AUDIT.json 为准。

## 试用限制

Windows 10/11、Node.js 20+、自己的 Codex ChatGPT 登录是先决条件。安装包不包含 Node.js，不支持与原版同时安装。Windows 完整注销/登录、Codex 退出重开和舍友的新设备真实账号安装尚需验收。额度接口仍可能临时超时。图片涉及的第三方参考角色权利不由本项目保证，使用范围以保留的素材声明为准。

未来发布前需重复执行审查与相关测试。公开问题反馈只收集复现步骤和错误类型，不收集令牌、登录文件或完整个人状态目录。
