### 可选的余量学习

“余量学习（本轮额度）”默认关闭，仅在用户从菜单手动授权后，允许当前账号的当前主额度周期进行研究；重启后关闭，切换账号、周期变化或失去新鲜成功额度快照也会关闭。每账号每周期最多尝试一次，失败或取消也计入尝试，不承诺产生新笔记。学习会使用你自己的 ChatGPT 订阅额度；配置付费 API provider 时拒绝启动。

研究使用 Codex CLI 的独立、只读、临时线程，通过 Codex 的联网检索阅读材料。发送的研究提示包含学习主题、输出要求和去重历史：控制器将本机已有 notes 笔记历史序列化后截取末尾最多 16,000 字符，交给 Codex 用于避免重复；因此已有笔记内容也会进入该模型请求。不要将敏感内容存入学习笔记。网络检索由 Codex 处理，不代表研究子进程拥有任意网络访问权限。临时线程不等于请求从未发送至服务方。

研究子进程临时禁用插件、外部 MCP、apps、shell 和多代理，使用只读沙箱且不允许外部审批，不改全局配置。研究不能写代码、规则或技能；控制器将返回笔记保存在本机安装数据目录的 learning 子目录，连同私有请求、状态和每轮尝试记录保留，不发送给维护者，也不复制账号或登录文件。停止学习先撤销启动授权，正在研究时等待子进程退出；停用安装不会自动删除这些个人数据。

学习仅在支持的 5 小时主额度窗口重置前 15–90 分钟、主额度剩余至少 40% 且周额度至少 50% 时尝试启动。最长 15 分钟，观测到主额度下降 10 个百分点或周额度下降 2 个百分点，或快照过期/查询失败时取消。这些是基于共享账号快照的软限制，包含其他线程消耗，无法精确归因，也不能保证精确消耗、取消时点或费用上限。用户可从菜单关闭；本次发布未进行真实学习调用验收。
